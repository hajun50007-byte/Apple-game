# 사과게임 (Fruit Box)

드래그로 사각형을 그려 **합이 정확히 10**이 되는 사과를 지우는 퍼즐 게임.
제한 시간 2분 안에 18 × 9 = **162개**의 사과를 얼마나 지울 수 있는지 겨룬다.

의존성 없는 순수 HTML + CSS + JavaScript 로 만들어져 있어 파일을 열기만 하면 바로 실행된다.

## 실행

```bash
# 방법 1 — 그냥 파일 열기
open index.html

# 방법 2 — 로컬 서버
npx http-server -p 8080
```

## 규칙

1. 1~9 가 적힌 사과가 가로 18칸 × 세로 9칸에 무작위로 배치된다.
2. 마우스 또는 손가락으로 드래그해 사각형 영역을 선택한다.
3. 선택한 사과들의 합이 **정확히 10**이면 사과가 화면 밖으로 떨어지며 사라지고, **사과 1개당 1점**을 얻는다.
4. 합이 10이 아니면 선택이 해제된다.
5. 제한 시간은 **120초**. 시간이 끝나면 최종 점수를 보여주고 다시 시작할 수 있다.
6. 최고 점수는 브라우저에 저장된다(만점 162점).

드래그 중에는 선택 영역의 합이 배지로 표시되고, 합이 10이 되는 순간 선택 상자가 초록색으로 바뀐다.

## 조작

| 입력 | 동작 |
| --- | --- |
| 마우스 드래그 / 터치 드래그 | 사각형 영역 선택 |
| `Enter` (타이틀 화면) | 게임 시작 |
| `Esc` (게임 중) | 타이틀로 나가기 |

## 모바일

- Pointer Events 기반이라 마우스·터치·펜을 같은 코드로 처리한다.
- 보드가 18:9 비율이라 세로 화면에서는 칸이 21px 정도로 작아진다. 그래서 **세로 화면에서는 게임 화면 전체를 90도 회전**시켜 가로 화면과 똑같은 크기(약 36px)로 플레이할 수 있게 했다. 기기를 가로로 돌리면 회전이 자동으로 풀린다.
- 보드에 `touch-action: none` 을 지정해 드래그 중 화면이 스크롤되거나 당겨지지 않는다.

## 구조

```
index.html          화면 구성 (타이틀 / 게임 / 결과)
css/style.css       스타일. 칸 크기는 --cell 변수 하나로 반응형 처리
js/board.js         보드 모델 — 생성, 영역 합, 교착 상태 판정 (DOM 비의존)
js/game.js          렌더링, 입력, 타이머, 애니메이션
tests/board.test.js 보드 로직 테스트
```

### 구현 노트

- **레이아웃**: 칸 크기를 JS 가 `--cell` 커스텀 프로퍼티로 계산해 넣고, 사과 위치는 CSS `calc()` 가 처리한다. 리사이즈 때 변수 하나만 바꾸면 162개 사과가 한 번에 재배치된다.
- **판정**: 드래그 사각형과 겹치는 열·행 범위만 계산해서(각 27회 비교) 선택 영역을 구하므로, 사과 개수와 무관하게 드래그가 가볍다. 선택 표시도 이전 사각형과 겹치는 부분만 갱신한다.
- **판정 여유**: 보이는 사과 지름은 칸의 0.76배지만 판정은 0.84배로 조금 넉넉하다. 손가락으로도 사과 사이 틈에서 선택이 끊기지 않는다.
- **애니메이션**: Web Animations API 로 사과가 살짝 튀어 올랐다가 회전하며 화면 밖으로 떨어진다. `prefers-reduced-motion` 을 켠 환경에서는 즉시 사라진다.
- **교착 상태**: 2차원 누적합으로 "합이 10인 직사각형"이 남았는지 검사한다. 시작 보드는 반드시 조합이 하나 이상 있도록 생성하고, 게임 중 조합이 모두 사라지면 시간을 기다리지 않고 결과 화면을 띄운다.

## 테스트

```bash
node tests/board.test.js
```

보드 생성, 영역 합, 교착 상태 판정을 검사한다. 교착 판정은 무작위 보드 1,000개에 대해 완전 탐색 결과와 대조한다.
